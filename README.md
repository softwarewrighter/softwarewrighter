I build software in public and write about it while I build it. Most of it is
one of three long projects:

- **A CPU approached from every direction.** MakerLisp's COR24, a 24-bit RISC
  for FPGAs: an emulator, an assembler, a tiny operating system, and a dozen
  languages hosted on it — each implemented in a *different* host language on
  purpose.
- **Historic machines brought back.** The IBM 1130, the IBM 390 and the RCA
  1802 in Rust and WebAssembly, down to console lamps and card hoppers.
- **Machine learning small enough to read.** Models and training loops built
  from scratch, plus sw-MLPL, a language for writing the maths so it reads like
  the paper.

Nothing here is a wrapper. If a repository says it emulates a CPU, the CPU is
in the repository.
