# Organisations

Fifteen GitHub accounts, because the work splits cleanly and a single account
with 242 repositories is a wall, not an index. If you would rather browse by
subject than by owner, start from [the topic list](../README.md#by-topic)
instead -- the topics cross organisation boundaries where the work does.

| Organisation | Repositories | What lives there |
|---|---:|---|
| [softwarewrighter](https://github.com/softwarewrighter) | 103 | The main account. Anything that has not earned its own organisation lives here. |
| [sw-embed](https://github.com/sw-embed) | 43 | COR24 and its toolchains: the 24-bit RISC machine, its languages, its operating system, its browser demos. |
| [sw-ml-study](https://github.com/sw-ml-study) | 24 | Machine learning studied by building it, including the sw-MLPL teaching language. |
| [sw-vibe-coding](https://github.com/sw-vibe-coding) | 20 | Experimental languages and agent-built projects: where a language idea goes before it settles. |
| [sw-comp-history](https://github.com/sw-comp-history) | 19 | Historic machines reimplemented: IBM 1130, IBM 390, RCA 1802. |
| [sw-langtools](https://github.com/sw-langtools) | 10 | The reusable compiler and ISA machinery the emulators share. |
| [sw-cli-tools](https://github.com/sw-cli-tools) | 9 | Small command-line tools, one job each. |
| [hardwarewrighter](https://github.com/hardwarewrighter) | 5 | The hardware side: boards, FPGAs, bench instruments, circuits. |
| [software-wrighter-lab](https://github.com/software-wrighter-lab) | 4 | Published surfaces: the blog, the campus, and the index over both. |
